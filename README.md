# Chaos Studio

### Friendship Edition — Choose Your Chaos!

Chaos Studio is an interactive friendship prank experience where playful threats become hilarious animated scenes.

Choose a scenario and watch the chaos unfold!

## Features

- Poolside push prank with a frog surprise
- Interactive cake-throwing scene
- Water splash attack
- Poke and run
- Funny friendship roasts
- Cinematic character animations
- Sound effects and interactive controls
- Responsive design for desktop and mobile

## Tech Stack

- HTML5
- CSS3
- JavaScript
- GSAP
- Canvas / SVG
- Vite
